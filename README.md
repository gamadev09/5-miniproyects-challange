Hey! This is my personal challenge to learn Java

Instead of building many small and disconnected projects, I decided to focus on five real-world applications that solve problems I actually have.

The goal is to improve each project over time, learn how real software is structured, and document my progress on GitHub.

Feel free to follow my progress or use this list to create your own challenge.

---

The 5 Real-World Java Projects Challenge

1. Automated File Organizer

A tool that automatically scans folders and organises files based on their extensions, categories, names, or custom rules.

Planned features

- Organise files by category
- Custom rules using JSON
- Dry-run mode
- Activity logs
- Duplicate-file detection
- Undo previous operations
- JavaFX graphical interface
- Scheduled folder organisation

Main concepts

- Java NIO
- File handling
- JSON configuration
- Exception handling
- Logging
- JavaFX
- Unit testing

2. Android Device Toolkit

Planned features

- Detect connected devices

- Run ADB commands

- Capture screenshots
- Record the screen

Main concepts

- "ProcessBuilder"
- Background processes
- JavaFX
- Asynchronous tasks
- Command execution

- Error handling

---

Challenge rules

- Every project must solve a real problem.
- Every project must include a proper README.
- Every important feature should have its own GitHub issue.
- Progress should be committed regularly.
- Each project should include screenshots or demonstrations.
- Projects should be improved instead of abandoned after the first version.
- AI can assist, but I must understand the code before using it.
- Finished projects should include a downloadable release when possible.
